Заметки для реализации (Expo + React Native)

  • Токены — единственный источник истины. Ни одного хардкод-HEX в компонентах: всё через CSS-переменные (в RN — объект темы). Смена темы = смена значений токенов.
  • Liquid Glass только на: GlassNavigationBar, GlassTabBar, GlassBottomSheet, плавающих кнопках и модалках (в RN — expo-blur + полупрозрачная заливка + верхний блик). Контентные карточки еды — плотные и читаемые.
  • Компоненты: BoxCard, OrderCard, MerchantCard, PrimaryButton/SecondaryButton, Input, OTPInput, StatusBadge, RatingStars, QRCodeCard, GlassTabBar/NavBar/BottomSheet — без одноразовых элементов.
  • Анимации реалистичны для RN: spring / fade / scale (Reanimated). Без 3D-трансформов и тяжёлых шейдеров.
  • Состояния Loading / Empty / Error заложены для Главной, Заказов и Карточки (см. карту экранов «▦ Экраны» в прототипе).
  • Дальше: приложение заведения (M-01…M-14) и супер-админ (S-01…S-09) — по тем же токенам и компонентам.
